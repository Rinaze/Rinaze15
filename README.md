## Диаграмма классов для задания Практика «Disk Tree»
![image](https://github.com/user-attachments/assets/6956aa83-7311-46b6-825b-db8bfc88a143)


### Описание основных сущностей

**1. Класс Node**

- **Поле child**:  
  Тип: SortedDictionary<string, Node>  
  Назначение: Хранит дочерние узлы (подкаталоги) с автоматической сортировкой по именам в лексикографическом порядке.
  
- **Конструктор**:  
  Node() - инициализирует пустой словарь для хранения дочерних элементов.

**2. Класс DiskTreeTask**

**Методы**:

1. **Solve(List<string> input)**  
   - Вход: Список строковых путей (например, ["Folder\\Subfolder", "Folder\\File"])  
   - Выход: Отсортированный список путей с отступами для визуализации иерархии  
   - Логика:  
     - Строит дерево через BuildTree 
     - Генерирует выходные данные через GetNames  

2. **BuildTree(List<string> input)**  
   - Вход: Список строковых путей  
   - Выход: Корневой узел (Node) построенного дерева  
   - Алгоритм:  
     - Разбивает каждый путь по разделителю \ 
     - Последовательно добавляет элементы в дерево  
     - Автоматически сортирует подкаталоги через SortedDictionary  

3. **GetNames(Node node, int level)**  
   - Вход:  
     - node: Текущий узел для обработки  
     - level: Глубина вложенности (для расчета отступов)  
   - Выход: IEnumerable<string> с отформатированными путями  
   - Форматирование:  
     - Корневые элементы без отступа  
     - Вложенные элементы с отступом level * пробелов  
   - Обход: Рекурсивный (в глубину)
